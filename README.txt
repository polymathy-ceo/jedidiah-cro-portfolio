Jedidiah Solomon portfolio redesign

Files:
- app/page.tsx
- app/globals.css
- app/layout.tsx

To install in the existing project, extract this ZIP in the project root and allow files to overwrite.

Portrait:
The page expects the client's portrait at public/jedidiah-portrait.jpg.
Create the public folder if it does not exist and copy the image there. Until then, a styled placeholder is shown.
The portrait itself is linked to https://x.com/thebelov_ed.

The design uses Google Fonts (Allura and DM Sans), so the browser needs an internet connection to load them.
