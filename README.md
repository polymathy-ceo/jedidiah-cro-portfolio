# Jedidiah Solomon — CRO Portfolio

A responsive, single-page professional portfolio starter for Jedidiah Solomon, Conversion Rate Optimization Specialist.

## Included

- Home, About, Services, Concept Studies, Process and Contact sections
- Responsive desktop and mobile navigation
- Scroll-triggered reveal animations and smooth scrolling
- Reduced-motion support for accessibility
- Email and LinkedIn contact links
- Search and social-sharing metadata
- Clearly labelled independent concept studies (no invented client results)

## Run locally in Termux

Use Node.js and npm in Termux, then run:

```bash
cd jedidiah-cro-portfolio
npm install
npm run dev
```

Open `http://localhost:3000` in your phone browser.

For a production build:

```bash
npm run build
npm start
```

## Important implementation notes

- The contact CTA uses `mailto:`. It opens the visitor's email app; it is not a database-backed enquiry form.
- No booking service, analytics account, A/B testing platform, CMS or backend has been configured.
- Google Fonts are loaded from Google Fonts when the visitor has an internet connection; the layout has local sans-serif fallbacks.
- No conversion percentages, testimonials, certificates or employment history have been fabricated.
